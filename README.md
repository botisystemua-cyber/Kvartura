# Kvartura — планувальник квартир (Finlandia 21B)

2D-редактор планування для приміщення на c/ Finlandia 21B, Torrevieja.
Мета — поділ приміщення (106,5 м² корисної площі) на дві квартири:
однокімнатну та двокімнатну.

**Запуск:** просто відкрий `index.html` у браузері — жодних серверів чи
встановлень. Працює і з GitHub Pages.

## Що вміє

- **Зовнішній контур зафіксований** — знятий з PDF-плану (масштаб 1:100),
  його змінити не можна. Позначено обидва входи.
- **Внутрішні стіни**: додавання (інструмент «Стіна»: клік — початок,
  клік — кінець), перетягування цілої стіни або її кінців, видалення (Del).
- **Двері**: інструмент «Двері» + клік по стіні; тягнуться вздовж стіни;
  подвійний клік — перевернути (4 положення).
- **Прив'язка**: до кутів і країв стін, до контуру та до сітки 5 см.
- **Автоматичний підрахунок площ** кожної кімнати після будь-якої зміни
  (растровий flood fill, крок 4 см) + сумарна площа внизу.
- **Undo/Redo**: Ctrl+Z / Ctrl+Shift+Z.
- **Варіанти планування**: збереження кількох іменованих варіантів у
  localStorage, швидке перемикання між ними, скидання до плану з PDF.
- **Експорт/імпорт JSON** — щоб обмінюватися варіантами між пристроями.
- Панорамування (тягни порожнє місце), масштаб (колесо/щипок), мобільні
  тач-жести.

## Гарячі клавіші

| Клавіша | Дія |
|---|---|
| `V` | інструмент «Вибір» |
| `W` | інструмент «Стіна» |
| `D` | інструмент «Двері» |
| `F` | вписати план у екран |
| `Del` | видалити вибране |
| `Ctrl+Z` / `Ctrl+Shift+Z` | скасувати / повернути |
| `Esc` | скасувати малювання / зняти вибір |

## Точність

Початкове планування перенесено з `Plano Calle Finlandia 21B.pdf` з
точністю приблизно ±10 см (розміри взято з проставлених на плані
розмірних ліній). Підписи площ рахуються по фактичному растру, тому для
кімнат біля зовнішніх стін можуть бути на кілька відсотків менші за
номінальні. Для ескізного планування поділу цього достатньо; робочі
креслення має робити архітектор.
