☁ Доступ до GitHub

Щоб зберігати проекти в GitHub, потрібен твій токен доступу (налаштовується один раз):

  1. Створити токен на GitHub ↗
  2. Repository access → Only select repositories → Kvartura
  3. Permissions → Contents → Read and write
  4. Натисни Generate token і скопіюй його сюди:

Токен зберігається лише у твоєму браузері і нікуди більше не передається.
